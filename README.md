# 🐺 Discord 人狼Bot (TomatoBot)

Discord上で、本格的かつカオスな人狼ゲームをプレイできる多機能Botです。
人間同士の心理戦はもちろん、独自の思考ルーチンを持つNPC（AIプレイヤー）を交えたプレイや、生成AI（Gemini）とRustエンジンを組み合わせた高度なゲーム体験を提供します。

## ✨ 主な機能と特徴

### 🎮 24種類の多彩な役職
スタンダードな役職から、場を大きく荒らす特殊役職まで網羅。複雑な陣営の絡み合いが毎試合異なるドラマを生み出します。
* **🏘️ 村人陣営 (14種)**: 村人, 占い師, 霊能者, 騎士, 共有者, 検死官, 市長, タフガイ, 猫又, 逃亡者, 怪盗, パン屋, 独裁者, 暗殺者, 死霊術師
* **🐺 人狼陣営 (6種)**: 人狼, 饒舌な人狼, 狂人, 狂信者, 妖術師, 分断者
* **🌟 第三陣営 (4種)**: 妖狐, テルテル, キューピッド, 純愛者, 神

### 🤖 Gemini × Rust のハイブリッドAIシステム
* **【大脳】生成AIによる圧倒的没入感 (Gemini API)**
  * **AI軍師のブリーフィング**: 初日の夜、人狼専用チャットにてAI軍師（またはNPC人狼）が、その村の配役に合わせた狡猾な騙り・潜伏の作戦を立案します。
  * **MVP寸評**: 試合終了時、AIがログを解析。熱血実況、冷徹なアナリスト、毒舌など、指定されたペルソナでMVPプレイヤーの活躍を解説します。
* **【小脳】超高速・論理思考エンジン (Rust NAPI)**
  * NPCの投票先や疑いの理由は、Rustで記述された別エンジンによって高速演算されます。発言数、CO（カミングアウト）の矛盾、過去の投票ラインを分析し、人間顔負けのロジックで追い詰めてきます。

### 🗣️ NPCガヤ＆パーソナリティシステム
人数不足を補うNPCは、ただランダムに動くわけではありません。
「好戦的」「慎重」「論理的」「お調子者」「ギャル」など8種類の性格（ペルソナ）を持ち、盤面状況（破綻、沈黙、ライン防御など）に応じて自動でチャットを発言（ガヤ）し、議論をかき回します。

### 🗺️ 動的なチャンネル制御トリック
DiscordのAPIをフル活用し、テキストチャンネルを動的に操作します。
* **🐺 人狼の隠れ家**: 人狼陣営だけがアクセスできる専用の秘密チャンネルを自動生成。試合終了後、証拠隠滅のために自動で物理削除されます。
* **🌀 セクター分断 (分断者)**: 「分断者」の能力が発動すると、生存者が強制的に「セクターα」と「セクターβ」の別チャンネルに隔離され、互いの状況がわからないまま朝の議論を行わされます。

### 🏆 ランクマッチ＆高度なレーティングシステム
Supabase（PostgreSQL）を活用し、プレイヤーの戦績やログを厳密に管理します。
* **独自のEloレーティング**: 単純な勝敗だけでなく、「村の人数（8人・12人以上でボーナス）」「勝利陣営の難易度（第三陣営や人狼陣営の勝利でボーナス）」を加味した高度なレート増減システム（K-factor変動）を採用しています。
* **8段階のランクシステム**: レートに応じて、ルーキー（1400未満）からレジェンド（2400以上）までのランク付けが行われます。
* **連勝・MVPボーナス**: MVP獲得（+5pt）や、3連勝・5連勝以上のプレイヤーにはさらなるレートボーナスが付与されます。
* **ゴースト賭け**: 死亡したプレイヤーが最終的な勝利陣営（村人・人狼・第三）を予想します。的中すると追加レートがもらえますが、敗北側が意図的に負けようとするトロール行為を防ぐため、「敗北時の的中ボーナスは最大+2まで」という安全装置が組み込まれています。
* **完全なログ保存**: 試合のチャットログ、投票ログ、タイムラインはすべてデータベース（`action_logs`）に保存され、後からの分析やリプレイが可能です。
* **シーズン自動リセット**: 毎月自動で全ユーザーのレートを1500、連勝数を0にリセットし、新シーズンに切り替えます。

### ⚙️ 快適なUIとホスト向け設定
* **直感的な操作**: ボタン、セレクトメニュー、モーダル（偽の検死レポート作成など）を活用し、コマンド入力不要の快適なプレイを実現。
* **プレミアムユーザー機能**: ユーザーのプラン（`free`, `founder`, `pro`, `host`, `supporter`）を判定し、サポーター以上向けに独自のルールプリセット保存機能（最大20枠）などを提供しています。

## 🚀 コマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| `!jinro` | 現在のチャンネルに募集ロビーを作成し、ゲームを開始します。 |
| `!stats` | 自分の戦績（現在のランク、試合数、勝率、レートなど）を確認します。 |
| `/preset [save/load/list/delete]` | 現在の村のルール設定を保存・呼び出し・管理します（※サポーター以上限定）。 |
| `/reset` | （※進行不能時のみ）現在のチャンネルのゲームを強制終了・リセットします。 |
| `/setup_verify` | 【管理者用】サーバーへの参加認証（ロール付与）ボタンを設置します。 |
| `/penalty` | 【管理者用】規約違反者のレートを強制没収し、初期値の1500にリセットします。 |
| `/sysinfo` | 【管理者用】Botの現在の稼働時間やメモリ使用量（ヘルスチェック）を確認します。 |

## 🛠️ 技術スタック
* **言語**: TypeScript, Rust (思考エンジン)
* **ライブラリ**: Discord.js, NAPI-RS (Node.js/Rust連携)
* **AIモデル**: Google Gemini API
* **データベース**: Supabase (PostgreSQL)
* **ホスティング**: Render (ヘルスチェック自動応答用Webサーバー内蔵)
