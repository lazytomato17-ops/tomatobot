# 🐺 Tomatobot

Discordで遊べる、シンプルな人狼ゲームBotです。

## 機能

- 人間プレイヤー1人なら論理パズル、2人以上なら通常対戦へ自動切替
- 参加者は人間とNPCを合わせて最大15人
- 4〜15人からプレイ人数を選択
- 人狼・占い師・騎士・霊能者の人数をロビーで設定
- 基本5役: 村人・人狼・占い師・騎士・霊能者
- 昼の議論、投票、夜行動、勝敗判定
- 役職と夜行動はDMで通知
- ロビー・昼・投票・夜・結果を統一したパネルで表示
- パネル更新式の残り時間通知と匿名の投票進捗
- Discordの相対時刻による正確なフェーズ終了表示
- 投票集計・夜明け・結果表示の間を設けたフェーズ進行
- 同票時の再投票と、再同票時の処刑なし判定
- 投票後に得票数と「誰が誰へ投票したか」を公開
- DM送信失敗時の開始停止と役職を変えない再送
- 人数に応じた45〜90秒の議論時間
- 長い表示名でも崩れにくい参加者表示
- 同じメンバーでの再戦
- NPCの会話・投票・占い・護衛・襲撃
- NPCごとの性格・疑い・投票記憶
- 占い発言と投票先の矛盾など、公開情報を使ったNPC推理
- プレイヤーの「怪しい人」指定をNPCが投票判断に利用

設定人数に足りない分は、ゲーム開始時にNPCが自動参加します。NPCがいないゲームでは、NPC発言やNPC用の疑い先メニューは出ません。NPCは外部AIを使わず、Bot内の軽量なルールで動きます。

## ゲームモード

- 一人用推理: NPCの中にいる人狼を、証言の矛盾から一度の告発で特定します。人間は真実を話し、人狼は必ず嘘をつきます。配役は開始時に固定され、表示された証言だけで答えが一つに定まる問題だけを出題します。
- 通常対戦: 人間の参加者が2人以上なら、これまでどおり議論・投票・夜行動で遊びます。全員の時間・情報・投票権は同じで、NPCも公開情報だけを使います。

一人用推理も4〜15人から登場人数を選べます。標準設定は7人です。追加質問は3回まで、告発は一度だけです。

## コマンド

| コマンド | 内容                                                                                    |
| -------- | --------------------------------------------------------------------------------------- |
| `/jinro` | 募集を開始します。実行者は自動参加し、設定人数に足りない分は開始時にNPCが補充されます。 |
| `/reset` | 進行中のゲームを終了します。メッセージ管理権限が必要です。                              |

## 役職編成

ロビーの「配役を設定」から各役職の人数を設定できます。残り枠は村人として自動計算されます。標準編成は次のとおりです。一人用推理では、人狼以外の役職はすべて「真実を話す証言者」として扱います。

- 4人: 人狼1、占い師1、村人2
- 5人: 上記に騎士を追加
- 6人: 上記に霊能者を追加
- 7〜10人: 人狼2、基本役職、残りは村人
- 11〜15人: 人狼3、基本役職、残りは村人

## セットアップ

Node.js 22以上が必要です。

```bash
npm install
```

`.env` を作成し、Discord Botトークンを設定します。

```env
DISCORD_TOKEN=your_discord_bot_token
PORT=10000
```

```bash
npm run dev
```

## 確認

```bash
npm run ci
npm run playtest
npm run build
```

## デプロイ

`Dockerfile` と `render.yaml` を使用できます。Render側で `DISCORD_TOKEN` を設定してください。
